INTEGRACIÓN CON LA APP BURBUJA

1) MODO DÚO
Burbujacraft usa el mismo Firebase de Burbuja y necesita que el usuario ya haya iniciado sesión.
Si publicas Burbujacraft en otro repositorio de GitHub Pages bajo el mismo usuario, por ejemplo:
  https://reyesdss.github.io/Burbujacraft/
y Burbuja está en:
  https://reyesdss.github.io/Burbuja-app-web/
ambos siguen teniendo el mismo ORIGEN https://reyesdss.github.io y pueden reutilizar la persistencia de Firebase Auth.

2) BOTÓN DESDE BURBUJA
La tarjeta de Juegos de Burbuja puede abrir Burbujacraft en la misma pestaña o en una nueva:
  https://reyesdss.github.io/Burbujacraft/

3) PUNTOS
Burbujacraft sincroniza los puntos conseguidos en:
  /shared/burbujacraftPoints

El documento contiene:
  total
  byUid.<UID>
  claimed

La app Burbuja puede escuchar ese documento y mostrar byUid[uid] en su sistema de puntos.

4) REGLAS
Las reglas actuales que ya tienes incluyen:
  match /games/{gameId} { allow read, create, update: if isMember(); }
  match /shared/{docId} { allow read, create, update: if isMember(); }
Por ello Burbujacraft v3 no necesita nuevas colecciones profundas ni cambios de reglas.

5) DOCUMENTOS DE JUEGO
Se crean documentos como:
  games/burbujacraft_world_v3
  games/burbujacraft_v3_player_<UID>
  games/burbujacraft_v3_mobs
  games/burbujacraft_v3_action_<UID>
  games/burbujacraft_v3_chunk_surface_<cx>_<cy>
  games/burbujacraft_v3_chunk_cave_<id>_<cx>_<cy>

No contienen contraseñas. Firebase Authentication sigue administrando el acceso.
